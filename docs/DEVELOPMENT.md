# 开发与使用说明

本文中的命令均从仓库根目录执行。版本更新见 [CHANGELOG](../CHANGELOG.md)，界面截图见[项目首页](../README.md)。

最低支持 macOS 14，使用 SwiftUI、AppKit `NSTextView` 和 `WKWebView`。当前为本机开发预览版，尚未完成开发者签名、公证或 App Store 分发。

## 构建与运行

需要 macOS 和 Swift 5.9 或更新的工具链。可以使用 Xcode，也可以使用 Command Line Tools。

```bash
bash scripts/build-app.sh
open dist/EasyMarkdown.app
```

打开示例：

```bash
open -a "$PWD/dist/EasyMarkdown.app" "$PWD/Examples/欢迎使用.md"
```

也可以直接运行 `swift run EasyMarkdown /绝对路径/文档.md`。需要生成带文件关联元数据的应用包时，请使用构建脚本。

构建脚本进行本机 ad-hoc 签名，保留 Sparkle 框架与辅助程序的原始签名，不会安装应用或修改系统默认打开方式。首次构建由 Swift 包管理器下载锁定的 Sparkle 2.10.1 依赖。Intel Mac 应在对应机器上构建；当前发布包仅支持苹果芯片，没有提供通用二进制安装包。

应用包支持简体中文、繁体中文和英文，主包包含 `zh-Hans.lproj`、`zh-Hant.lproj` 和 `en.lproj` 资源。验证原生界面语言请运行打包后的 `.app`；直接 `swift run` 的裸可执行文件不包含主应用包的语言元数据。更新应用后需完全退出旧进程，再打开新包。

## 常用操作

通过菜单“EasyMarkdown → 关于 EasyMarkdown”可以查看应用图标、当前版本与构建号，并点击 GitHub 仓库链接访问项目。

### 软件更新

菜单“EasyMarkdown → 检查更新…”与“设置 → 软件更新”共用更新流程。设置显示当前版本、上次检查时间及“每天自动检查更新”开关，默认开启。检查只在应用运行期间调度，约每天一次，不安装后台常驻服务；下载和安装均需确认，不发送系统信息统计。手动检查会显示已是最新版本或具体失败原因，后台失败不打断编辑。

更新包下载完成后可安装并重新启动；存在未保存文档时沿用原生保存、放弃、取消流程，保存失败或取消退出不会强行关闭应用。请先将应用安装到 Applications；从只读磁盘映像或系统转移的临时位置运行时，检查入口会显示安装说明。裸可执行文件不支持更新。

0.1.23 及更早版本没有更新组件，需要手动安装一次 0.1.24 或更新版本。当前更新源包含项目公开发布的预发布版本；未发布的标签、草稿发布不会被纳入。安装包仍使用临时签名，更新签名不等于苹果开发者签名或苹果公证。

### 制作与发布更新

应用内置更新公钥；对应私钥仅保存在本机钥匙串，条目账户为 `app.easymarkdown.mac.updates`。更换发布机器前须妥善迁移密钥，不能重新生成公钥后期望旧客户端继续接受更新。禁止将私钥、导出文件或访问凭证提交到仓库。

```bash
python3 scripts/prepare-release.py
```

该命令构建发布应用、检查版本与密钥匹配、生成可拖入 Applications 的磁盘映像及校验和，并调用 Sparkle 官方工具生成签名更新源，不生成增量更新。产物位于 `dist/release-<版本>/`，包含磁盘映像、`SHA256SUMS.txt` 和 `appcast.xml`。更新说明取自版本记录的当前章节；构建号用于比较新旧版本，更新源声明最低系统版本和苹果芯片要求。已有发布构建可加 `--skip-build`，脚本仍会检查版本及签名。

先提交推送源码，用对应版本标签发布 GitHub 预发布版本，上传磁盘映像和校验和并确认公开下载成功，再将产物中的 `appcast.xml` 原样复制到 `updates/appcast.xml` 并提交推送。客户端固定读取 `https://raw.githubusercontent.com/OldSixYao/EasyMarkdown/main/updates/appcast.xml`，不使用忽略预发布版本的“最新正式版”接口。更新源、内嵌更新说明和安装包都经过签名验证；已签名的更新源不得手工修改，必须由脚本重新生成并签名。

### 语言与默认编辑器

在“设置 → 应用语言”中选择“跟随系统、简体中文、繁體中文、English”。选择会立即保存，应用文字和原生替换/保存界面在下次启动时统一生效；请先保存文档，再退出并重新打开应用。不会自动重启或关闭未保存文档。默认跟随系统，系统首选语言不在支持范围且没有其他受支持的首选语言时使用英文。

语言选择保存在应用自身的 `appLanguage` 设置，并同步应用域的 `AppleLanguages`；启动时在 AppKit 初始化之前解析。选择“跟随系统”会删除应用自己的 `AppleLanguages` 覆盖，恢复系统语言选择。不写入 macOS 全局语言偏好；切换语言不翻译或重写文档中的现有内容。

在“设置 → 默认编辑器”中选择文件类型，再点击“设为默认”，可把当前运行的 EasyMarkdown 设为该类型的系统默认打开应用。支持 Markdown（.md、.markdown、.mdown、.mkd）、TXT、JSON、XML、YAML（.yaml/.yml）、TOML、INI、CONF（.conf/.cfg/.cnf）、ENV（.env）、Properties 和 JSONC，初始选中 Markdown；单项按钮只修改所选格式及其扩展名别名对应的类型。点击列表标题右侧的“全部设为默认”，可一次设置列表中的全部内置类型与自定义后缀；相同系统类型只请求一次，跳过已经关联的类型。状态通过系统实时查询，已指向当前应用时对应按钮禁用；回到应用或重新打开设置时刷新。macOS 可能逐类型要求确认；取消后停止后续请求，其他失败会继续处理剩余类型，最终显示未成功类型和原因。仍未生效时可通过 Finder“显示简介 → 打开方式 → 全部更改”处理。

建议先把应用安装到 Applications 再操作；只读磁盘映像中的应用和裸命令行程序不能执行此设置。系统按应用标识保存关联，实际打开时可能选择应用程序目录中同标识的已安装副本。安装版与构建版同时存在时，默认状态按应用标识识别，不因路径不同误报失败；缺失应用标识时仅接受同一路径。该选项不更改正在打开的文档内容、语言或保存偏好。系统文件类型关联按 UTType 生效，TXT 使用系统的纯文本类型。若需要恢复其他编辑器，请使用 Finder 的“打开方式 → 全部更改”。

默认文件类型以原生单选表格展示，列表直接持有独立滚动容器；点击行选择，或聚焦列表后用方向键切换。列表约显示 5 项，右侧常驻显示垂直滚动条，可拖动滑块查看全部类型，不受系统自动隐藏滚动条偏好影响。每行显示“已设为默认”（绿色勾选）、“部分已设为默认”（同一组别名尚未全部关联）、“其他应用”或“未设置”，来自当前系统查询。选中类型后，下方显示默认应用详情，再点击“设为默认”应用修改。应用重新激活、设置出现和设置完成后刷新全部行；同一系统类型可能对应多个扩展名，相关行会一起更新。

在列表下方输入新后缀（如 `log` 或 `.log`），点击“添加”或按回车保存到本机列表。支持 1–32 个英文字母、数字、连字符、下划线或加号，自动去掉开头的点、首尾空白并转为小写；每次添加一个后缀，不接受完整文件名、路径、通配符或多个点。重复后缀会选中已有类型并滚动到该行。新增类型显示在列表顶部并自动选中，点击“设为默认”或“全部设为默认”后修改系统关联。

选中自定义行时可点击“移除”，只删除列表记录，不撤销系统默认应用；要恢复其他编辑器请通过 Finder 的“打开方式 → 全部更改”。自定义项保存在应用偏好 `customEditorExtensions` 中，重启后保留。系统已识别的后缀复用现有 UTType，未识别的后缀使用系统生成的动态 UTType；设置结果以系统重新查询为准，失败会显示原因。自定义后缀不会改写应用包或绕过文件编码检查，未知类型仍以纯文本查看，二进制文件不支持编辑。

| 操作 | 快捷键或入口 |
| --- | --- |
| 打开 | `⌘O`，或拖入文件 |
| 保存 | `⌘S` |
| 另存为 | `⇧⌘S` |
| 编辑 / 保存并完成 | `⌘E` |
| 查找 | `⌘F` |
| 查找下一个 | `⌘G` |
| 查找上一个 | `⇧⌘G` |
| 查找并替换 | `⌥⌘F`，或阅读搜索条的“替换…” |
| 设置 | `⌘,` |

点击“完成”会保存并返回阅读视图；保存失败时保留编辑模式和内容。

阅读模式下，在文档中输入文字、按退格或删除键，以及使用 `⌘X`、`⌘V` 时，会提示“当前是只读模式，是否开始编辑？”。点击“确定”进入源码编辑并聚焦正文；点击“取消”或按退出键继续阅读，保留正文及选区。触发提示的按键只用于请求编辑，确认本身不写入文字或保存文件。长按期间不会连续弹窗。方向键、翻页、空格滚动、回车激活按钮、Tab 切换焦点、复制和查找沿用阅读行为，查找框输入正常处理；已在编辑或分栏模式时无需再次确认。

保存和格式化会保留正在查看的内容与选区；全文格式化或换行转换后按内容重新定位，分栏关闭同步时两侧独立保持位置。源码编辑点击“完成”后，排版阅读跳转到源码当前所在的段落。格式化保持原生撤销与重做，保存统一换行符时也保留此前的编辑历史。

阅读搜索条显示“共 N 处”，并提供“上一个”“下一个”循环定位。搜索按可见正文进行不区分大小写的字面匹配，可跨同一段落的粗体、链接等行内格式，不跨独立段落；代码正文参与计数，按钮和隐藏内容不计入。输入约合并 120 ms 后更新，当前项高亮，正文刷新后重新计数并定位首项。大文件截断时显示“当前预览共 N 处”，只统计显示部分。

TXT、JSON、XML 和配置文件的阅读使用原生只读文本视图，显示全文；查找使用系统原生查找栏。进入编辑后沿用同一文本视图，分栏右侧是只读原文预览。文档标记格式仍使用排版阅读和正文搜索。

点击“替换…”会进入源码编辑模式并带入阅读搜索词，展开系统原生替换栏；支持单次和全部替换、空文本替换、撤销和重做。替换针对源码全文，包括 Markdown 标记、链接地址及隐藏内容，因此结果数可以与阅读搜索不同。替换后保留未保存状态，按 `⌘S` 保存；切换入口不修改普通复制剪贴板。在编辑和分栏模式，查找及前后查找快捷键均作用于源码编辑器。

编辑后顶部常驻橙色“未保存”标记，支持点击“保存”继续编辑，或按 `⌘S`。保存过程中显示“正在保存…”，成功后显示“已保存”；失败后保留红色“保存失败 · 未保存”提示。恢复草稿不会清除原文件未保存状态，也会保留已检测到的外部版本，仍需确认更新。

已打开的文档在其他位置保存后，阅读、编辑和分栏模式都会先保留当前内容，弹出所属窗口的“确定 / 否”确认框。有未保存编辑时会说明更新将放弃这些修改。点击“确定”重新读取磁盘最新内容；点击“否”或按退出键保留正文、编辑状态、选区、阅读位置和撤销记录，不回写磁盘。同一外部内容不重复提示，检测到新内容后重新询问；仅文件时间等元数据变化不提示。

后台标签、最小化窗口和应用后台期间暂存提醒，回到对应文档后再显示；保存、关闭或查看外部版本的对话框结束后才询问。确认后读取失败仍保留内容并提示原因；读取期间继续编辑会取消旧载入并重新询问，关闭和另存为也会取消过期结果。

提示条保留“查看外部版本”“加载外部版本”和“另存为”入口，手动加载共用同一确认流程。确认加载后统一更新正文、预览、统计与保存基线，清理旧撤销和过期草稿。保留内容后继续编辑不会自动覆盖外部文件，保存仍会检查冲突；关闭后重新打开会读取磁盘版本。首版没有自动合并或强制覆盖按钮。

Markdown 工具栏只在源码编辑和分栏模式显示。选中文字后点击粗体、斜体等按钮可包裹选区，再次使用可移除对应标记；标题、引用和列表按所在行或选中的多行处理。没有选区时插入可直接替换的占位内容，链接/图片会选中待填写的地址，所有操作使用编辑器原生撤销。

鼠标移到顶部工具栏按钮时，按钮显示强调色背景和边框；停留片刻会出现系统名称提示。标题和“更多”菜单也支持这一效果，禁用按钮不显示悬停高亮。

阅读及分栏预览中，鼠标悬停在行内代码或代码块上时，右上角显示复制按钮；也可通过 Tab 聚焦按钮，再按空格或回车复制。复制内容为代码正文，保留空格、缩进及渲染后的换行，不含 Markdown 标记。成功或失败反馈约显示 1.5 秒，代码块横向滚动时按钮保持在右上角。TXT、JSON、XML 整篇纯文本预览及截断的大文件预览不提供此按钮。

分栏视图中，滚动源码或预览都会带动另一侧。顶部蓝色链条图标表示同步开启，点击后可以独立滚动，再次开启时按源码当前阅读位置对齐。

后台文档窗口空闲约 30 秒后释放排版阅读视图，保留低分辨率窗口内容快照、阅读位置和当前搜索项；切回窗口时重建阅读视图。源码编辑器和未保存内容保持完整。重新打开、外部内容变化或布局明显改变时，位置恢复仍采用内容锚点的尽力匹配。

图片只在视口附近加载，离开较远区域后释放并保留尺寸占位。图片预算不足时显示暂缓提示，可滚动后重试或点击“查看原图”；远程图片默认仍关闭。原图查看使用系统默认应用，不会改写图片文件。

应用使用蓝色圆角底、白色折角文档和 Markdown 标记的专用图标，已配置 Finder/Dock 图标和运行时应用图标。图标源绘制脚本为 `scripts/generate-icon.swift`，执行 `swift scripts/generate-icon.swift` 可重新生成 `Assets/AppIcon.png` 和 `Assets/AppIcon.icns`，构建时自动打包。

## 验证

不依赖 XCTest 的核心回归检查：

```bash
bash scripts/check-core.sh
```

实际应用窗口与 WebKit 检查（需要已登录的 macOS 图形会话，会短暂打开测试窗口）：

```bash
bash scripts/check-app.sh
```

第二条命令构建 Debug 应用并进行 Markdown 渲染、外部修改确认与原子替换加载、段落位置保持、分栏预览、本地编辑冲突、另存为、HTML 过滤、图片加载、删除和草稿恢复检查。结果与阅读预览截图位于 `.build/smoke/`。测试完成后，可以重新运行 `bash scripts/build-app.sh` 生成 Release 应用。

外部修改检查包含真实按钮点击、退出键、同版本去重、新版本重问、后台标签与最小化延后、读取失败、继续编辑以及关闭和另存为后的过期回调；截图保存在本机 `.build/smoke/external-confirmation/`。

单独运行外部修改检查：先执行 `bash scripts/build-app.sh debug`，再运行 `dist/EasyMarkdown.app/Contents/MacOS/EasyMarkdown -appLanguage zh-Hans --external-change-test "$PWD/.build/external-change"`。检查使用生成的专用文档和独立标签偏好，不改动现有文档。

只读编辑确认专项：`bash scripts/check-read-only-edit.sh`。使用生成的 TXT、Markdown、JSON 和 YAML 文档，实际分发键盘事件并点击确认按钮，检查输入、剪切粘贴、取消及退出键、长按去重、原生选区保留、确认后焦点与输入/撤销、查找框输入、分栏预览、已有面板及关闭时清理。报告和截图位于 `.build/read-only-edit/`，完整应用回归也包含此项。可对打包的调试应用使用 `--read-only-edit-test <输出目录>` 单独执行，并通过 `-appLanguage` 指定界面语言。

多语言真实窗口检查：`bash scripts/check-languages.sh`。分别在新进程验证简体、繁体、英文及跟随系统的解析/回退，检查设置、菜单、预览、原生替换和保存取消；报告和截图位于 `.build/languages/`。使用进程参数模拟语言，偏好写入/重置检查使用独立的临时 UserDefaults 域，不改变用户的语言选择。完整应用回归固定以简体中文启动，避免受个人语言设置影响。

安装完整 Xcode 后，也可使用 `swift test` 运行 `Tests/EasyMarkdownCoreTests` 中相同的 52 个核心测试。仅安装 Command Line Tools 的环境可能不提供 XCTest。

更新专项检查：`python3 scripts/check-updates.py`。使用系统临时目录中的调试应用副本、随机独立偏好域和本地服务器，覆盖版本与签名检查、失败路径、下载安装重启及未保存文档处理；不会替换已经安装的应用。测试副本使用带随机后缀的独立名称，不声明文档类型，也不沿用正式应用的本地化显示名称；完成后注销系统注册，检查注册已清除，并改为 `.fixture` 后缀保存诊断内容，防止干扰按名称启动正式应用。测试副本才允许本地更新地址，正式包固定使用 HTTPS。报告和日志归档到 `.build/updates/`，诊断副本留在命令输出的系统临时目录，均不提交仓库。

应用检查也会人为阻塞文件服务和草稿服务，验证关闭后的会话在 I/O 恢复前即可释放；检查小文档撤销历史淘汰、2 MiB 文档自动降低历史组数，以及现有原生撤销/重做功能。

性能保护回归也包含在应用检查中：长行高亮降级与 Unicode 链接范围、大文件顶部及宽度变化后的局部排版、后台格式化的撤销/重做与过期任务丢弃、同名标题及混合锚点冲突、阅读搜索索引复用与关闭/刷新后的失效。报告保存在本机 `.build/smoke/`。

语法高亮专项检查：`bash scripts/check-configurations.sh`。除各格式颜色和配置文件操作外，还在真实阅读、编辑与分栏窗口中连续跨屏、反向及跳到底部，立即核对新视口的临时颜色；覆盖窗口缩放、多行词法上下文及编辑后的缓存失效。滚动后不等待输入防抖，也不直接调用高亮方法。报告和测试截图保存在本机 `.build/configurations/`。

轻量化专项检查也包含在应用回归中，可单独运行：


覆盖大文件原生编辑与撤销回到已保存状态、保存后继续撤销、同目录共享监听与无关事件过滤、新旧草稿和持续输入恢复点、图片总量与离屏释放、远程响应限制与取消、后台休眠后位置和搜索项恢复。测试仅使用生成的专用文件和窗口。

输出目录必须尚不存在。脚本直接编译当前生产源码，生成独立标识且不声明文件关联的临时测量应用，结束时注销系统注册并改为非应用后缀。可用 `--source /绝对路径/源码副本` 编译对照版本；前后必须使用相同脚本、文档和测量口径，并顺序运行，避免多个测量实例互相影响。原生路径分别记录首次与热调用，网页路径检查节点保留情况；交互测量包含输入合并和跨进程传输，并注明探测采样间隔。扩展内存测量计入归属到应用的网页辅助进程，覆盖一、五、十窗口、后台空闲、配置阅读和持续编辑；测试数据与报告均保存在本机输出目录。

配置文件专项检查：`bash scripts/check-configurations.sh`。覆盖 11 种配置文件及命名场景、7 组默认编辑器选项，以及逐行状态刷新、自定义后缀校验/持久化/去重/移除和失败处理，结果及 YAML 分栏截图位于 `.build/configurations/`。默认关联写入使用注入的测试函数，不改动用户的真实默认应用；完整应用回归也包含这些检查。

默认编辑器专项检查：`bash scripts/check-default-editor.sh`。在完整设置窗口中验证列表滚动条常驻、滚动到底部、鼠标与键盘选择、重复后缀定位及新增/移除后的可见性；批量设置覆盖全部类型与自定义项、类型去重、跳过已关联类型、失败后的继续处理、取消停止及结果重新查询。同应用多副本、同名不同标识及缺失标识使用未注册的资源包模拟；另行只读核对系统实际关联，设置写入仍使用注入接口。报告和截图位于 `.build/default-editor/`，使用独立临时偏好。

配置专项和完整应用回归同时检查各格式的实际原生文本颜色：字符串与注释互不覆盖、无引号配置值、地址与网段、列表、转义和多行内容、数值与关键字、XML 正文及原始字符数据、Markdown 代码与链接的优先级、滚动后的多行上下文、长内容处理上限，以及原生阅读和分栏预览的一致性。颜色仅使用临时显示属性，不修改正文和保存状态。配置专项还会生成浅色与深色的 JSON 编辑窗口及 YAML、XML 原文阅读截图；完整应用回归另行核对排版阅读中代码块的字段、字符串和数值着色。


## 行号与文档标签

设置中的“显示行号”和“启用文档标签管理”默认开启，分别保存在 `showLineNumbers` 与 `documentTabsEnabled` 本机偏好中，更改即时生效。行号只出现在源码编辑区和分栏左侧，按实际换行从 1 开始编号，自动折行不重复编号；阅读视图及外部版本预览沿用现有展示。行号不参与正文复制、保存或撤销。

多份文档默认合并到系统原生标签栏，可点击切换、拖动排序、关闭或移到独立窗口。`⌃Tab` 与 `⌃⇧Tab` 切换下一、上一标签，`⌘W` 关闭当前文档并保留未保存确认。“新建标签…”及原生标签栏的加号打开文件选择面板。关闭标签管理会即时拆分已打开文档，重新开启会合并文档；保存或关闭对话框结束后再应用最新选择。设置、起始和关于窗口独立显示。

专项检查：`bash scripts/check-editor-workspace.sh`。覆盖行号开关、折行、撤销重做、输入法组合、阅读与分栏显示范围、原生标签切换和重排、重复打开、关闭取消后拆分、设置窗口焦点、另存为标题、大文件局部排版及标尺释放；真实窗口截图和结果位于 `.build/editor-workspace/`。完整应用检查也包含此项，新增偏好测试使用临时独立域并在退出时清理。

该专项同时检查长文档的标签切换、后台休眠恢复、普通保存、换行转换保存、格式化后的选区与可见内容、分栏独立位置及恢复同步，以及源码保存完成后的排版阅读位置。位置检查结果保存在本机 `.build/editor-workspace/positions/`。

## 文档状态栏

阅读、源码编辑和分栏模式的窗口底部始终显示全文总行数和字符数；存在选区时，右侧追加已选行数和字符数。所有支持的文档类型共用此状态栏。鼠标停留时显示“字符数不含空白字符”，辅助功能可读取完整统计。

字符数按完整字符计数，排除空格、制表符、换行及其他空白；中文、组合表情和组合文字各按一个字符计算，标点与源码标记参与统计。行数按实际换行计算，自动折行不增加行数；空文档为 1 行，末尾换行后的空行计入全文行数。选区恰好结束于下一行开头时不计该行，只选空白仍显示选区且字符数为 0；多个原生选区的字符与行合并去重。

原生文本视图使用 UTF-16 稀疏前缀索引，不保留第二份全文；编辑按实际文本存储变化更新，选区变化只查询边界附近的计数。组合字符边界受影响时扩大重算范围，全文替换时重建。行数沿用行号规则，独立于行号开关。鼠标拖选的中间范围和键盘扩选均会更新统计，刷新合并到支持鼠标跟踪的运行循环，不必等待松开鼠标。

文档标记的排版阅读同样支持选区统计，按浏览器实际选择的可见文字及其中的换行计数，自动折行不额外增加行数；全文统计仍以原始文档为准，包含源码标记。排版选区变化约合并 16 毫秒后发送，字符数继续按完整字符排除空白。分栏状态栏跟随当前操作窗格的选区，切换模式清理旧选区；外部版本预览不会发布主文档统计，每份文档独立保存快照。

`bash scripts/check-core.sh` 覆盖统计口径、随机编辑与撤销对照、组合字符边界和大文档局部扫描；`bash scripts/check-editor-workspace.sh` 同时覆盖各模式常驻显示、原生多选区、拖选尚未结束时的数字与实际状态栏文字、排版阅读连续扩选、撤销重做、输入法组合、行号开关、分栏选区来源切换、外部版本隔离、各格式、格式化及外部加载。状态栏截图位于 `.build/editor-workspace/statistics/`；语言检查覆盖统计文案、辅助功能信息和窄窗口。

## 配置文件

支持 YAML（.yaml/.yml）、TOML（.toml）、INI（.ini）、CONF（.conf/.cfg/.cnf）、ENV（.env）、Java Properties（.properties）、JSONC（.jsonc）。打开方式包括 Finder“打开方式”、应用内 ⌘O 和拖入文件；在设置的“默认编辑器”中选中格式并点击“设为默认”，可以按类型设置系统关联。选择和打开文件不会自动改变关联。

配置文件的阅读视图显示源码，支持基础语法高亮和原生查找，编辑及分栏模式支持原生查找替换、撤销、保存与外部冲突保护。保留注释、键顺序、空白、带 BOM 的原编码及一致 CRLF；不执行环境变量或配置中的脚本，不进行 YAML/TOML/INI/JSONC 语法验证或自动格式化。高亮是辅助显示，不是完整的语法解析器；超过大小阈值时以默认文字颜色显示全文。

原生文本视图中，识别到的字段名显示为绿色，文本值显示为蓝色，数字、布尔值和空值显示为紫色，注释显示为灰色。JSON 和 JSONC 区分字段名与字符串值；YAML 以及其他配置格式的无引号文本、网址、地址、网段和列表值也参与高亮，类型按完整值判断。XML 的标签、属性名为绿色，属性值、标签间的正文和原始字符数据为蓝色。标点和结构符号保留默认文字颜色。配色跟随浅色或深色外观，源码编辑、原文阅读和分栏右侧共用相同规则。

打开面板会显示隐藏文件，`.env`、`.env.local`、`.env.production` 等会识别为环境配置。无标准扩展名文件的 Finder 类型关联取决于系统识别，不能保证 `.env` 或 `.env.*` 都能单独设为默认；可以使用应用内打开或拖入。不会注册 `.local`、`.production` 等通用扩展名，或读取用户真实环境变量。二进制 plist 和其他非文本配置仍按编码规则拒绝。

## 当前限制

- “同步”只覆盖已写入本机文件系统的变化；其他编辑器未保存的内容、云服务尚未下载的内容不可见。
- 当前支持 UTF-8、带 BOM 的 UTF-8/UTF-16，并尽量保留原编码及一致的 CRLF 换行；其他编码和二进制文件明确拒绝读取。
- 首版文件上限为 24 MB；文档标记排版预览超过 500,000 个 UTF-16 码元时降级为截断的纯文本，跨进程正文最多 1,500,000 字节且不切断代理对。原生阅读和编辑器显示全文，长文本基础高亮有单独的大小限制。
- 本地图片访问限制在文档目录内，暂不加载 `../` 指向目录外的图片。当前应用未启用 App Sandbox，商店分发所需的目录授权流程尚未实现。
- 图片预览的本地文件与远程响应最多 64 MiB，内嵌 data 地址最多 2 MiB，矢量源最多 2 MiB。位图限制 3,200 万像素，动画最多 300 帧，按最大帧宽 × 最大帧高 × 帧数 × 4 估算解码预算；矢量每张预留 16 MiB。每份文档及其冲突预览合计最多准入 32 张、128 MiB 估算像素与 64 MiB 原始字节，应用合计最多 64 张、256 MiB 估算像素与 128 MiB 原始字节。同一视图同源图片复用原始资源，离屏与关闭时归还预算。预算是资源准入估算，网页内部、图形缓存和矢量复杂度仍影响实际物理占用，不是应用堆内存硬上限。
- 原生撤销最多保留 100 组，按文档 UTF-8 大小和 32 MiB 估算预算降低组数，至少保留 1 组。较旧的操作会被淘汰；实际占用还取决于撤销内容、分组及重做记录。
- 源码基础高亮仅处理小于 200,000 字节的文档；超过 4,096 个 UTF-16 码元的逻辑行显示默认文字颜色。正则匹配使用约 8 ms 的尽力处理预算，超时可只显示部分颜色；该预算不涵盖文本布局，也不是主线程耗时的硬上限。
- XML 格式化拒绝 DTD 和实体声明，不承诺保留所有排版细节；JSON 格式化使用 Foundation 的数据模型。格式化解析在后台串行执行；编辑、保存、关闭或内容刷新后会丢弃过期结果，输入法组合文字期间不应用替换。已经开始的系统解析不能强制中断，应用格式化结果时的文本替换和排版仍在主线程完成。
- 首版不提供新建文档、富文本式 Markdown 编辑、文件夹工作区、插件、PDF 导出或自动冲突合并。
- 滚动保持采用内容锚点的尽力恢复；段落被删除、重复内容变化、复杂布局变化时可能退回相对位置。
- 中文输入法的实际交互、关闭/退出对话框、系统文件关联和不同 macOS 版本仍需要人工回归。当前机器上的自动检查不等于 macOS 14 实机兼容性验证。
