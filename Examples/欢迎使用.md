# 欢迎使用 EasyMarkdown

一个安静的 macOS 文档阅读窗口。**阅读为主，随手修改。**

## 试试外部修改确认

1. 在 EasyMarkdown 中打开这份文档。
2. 用另一个编辑器打开同一个文件，修改这段文字并保存。
3. 回到这里，应用会提示文档已被修改。点击“确定”加载最新内容，点击“否”保留当前内容。

> 如果本地还有未保存的修改，确认更新会放弃这些修改。点击“否”或按退出键可保留；同一次外部修改不会重复询问，再次修改时会重新提示。

## 阅读与编辑

- 点击工具栏的「编辑」修改源码。
- 使用 `⌘S` 保存，或点击「完成」保存并返回阅读。
- 使用 `⌘F` 查找，`⌘E` 切换编辑与完成。
- 在编辑状态下选择「分栏」，边写边看预览。

### 一些 Markdown 排版

| 格式 | 支持 |
| --- | --- |
| Markdown | 阅读、源码编辑、分栏预览 |
| TXT | 阅读、编辑 |
| JSON / XML | 语法高亮、编辑、格式化 |

```json

  "name": "EasyMarkdown",
  "platform": "macOS",
  "confirmExternalChanges": true
}
```

## 文件与隐私

应用离线运行，默认不加载远程图片。你可以在设置中调整字号、阅读宽度和外观。

本地图片以当前文档目录为根目录解析。外部网页会在默认浏览器中打开。
